# Third-party content: LegendKeeper documentation

The files in this folder are copies of LegendKeeper's public developer documentation. They are **not** covered by this repository's MIT license and remain the property of their authors (LegendKeeper).

| File | Source |
|---|---|
| `openapi.json` | https://www.legendkeeper.com/api/v3/openapi.json |
| `sdk-guide.md` | https://www.legendkeeper.com/developers/guide/ |
| `style-guide.md` | https://www.legendkeeper.com/developers/style/ |
| `quickstart.md` | https://www.legendkeeper.com/developers/quickstart/ |

They are kept here unchanged as the project's sources of truth. The code generator reads `openapi.json`, and the SDK's behaviour contract (`docs/SDK_CONTRACT.md`) cites the guide by section. `FETCHED.md` records the fetch date, the spec version and the sha256 of `openapi.json`. For current versions, see the URLs above.
